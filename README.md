# 🤖 LAPBOT ULTRA – Voice Controlled Desktop Assistant

LAPBOT ULTRA is an advanced Python-based voice-controlled desktop assistant designed to automate system tasks, respond to voice commands, and optionally interact with AI for intelligent conversations.  
It demonstrates real-world implementation of speech recognition, automation, multithreading, and AI integration.

---

## 📌 Project Description

LAPBOT ULTRA works like a Jarvis-style assistant that listens to user voice or text commands and performs actions such as:

- Opening and closing applications  
- Searching Google and YouTube  
- Controlling keyboard and mouse  
- Answering local questions and solving math  
- Running user-defined macros  
- Speaking responses using Text-to-Speech  
- Using AI responses via OpenAI (optional)

This project is ideal for college submission, internships, and GitHub portfolios.

---

## ✨ Features

- User Voice Input  
- Speech Recognition Module  
- Command Detection / Intent Parsing  
- Action Queue System (Thread-Safe)  
- Automation Execution (Apps, Mouse, Keyboard)  
- Local Response System (Offline Q&A, Math)  
- Optional ChatGPT Mode  
- Text-to-Speech Output  
- Fallback System (Web Search)  
- Macro Engine (Save & Run Commands)

---

## 🛠 Technology Stack

- Programming Language: Python 3  
- Libraries:
  - speech_recognition
  - pyttsx3
  - pyautogui
  - requests
  - selenium (optional)
- AI Integration: OpenAI API (Optional)
- Platform Support: Windows, macOS, Linux
- Version Control: GitHub

## ⚙️ Installation

### Clone the Repository
```bash
git clone https://github.com/your-username/lapbot-ultra.git
cd lapbot-ultra
```

### Install Dependencies
```bash
pip install speechrecognition pyttsx3 pyautogui requests selenium webdriver-manager
```

---

## ▶️ How to Run

### Voice Mode
```bash
python lapbot_final.py
```

### Text Mode
```bash
python lapbot_final.py --text-mode
```
